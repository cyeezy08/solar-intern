# Solar Calculator

A solar calculator and proposal estimator built as a software engineering portfolio project focused on the renewable energy space.

## Overview

This project is a small full-stack web app that estimates solar system sizing, annual energy production, monthly savings, and payback period based on roof area, panel efficiency, and average sunlight hours.

It is designed to show practical frontend, backend, and product-thinking skills in a domain relevant to solar energy and sustainability.

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- PostgreSQL
- Drizzle / Kysely
- Docker

## Features

- Roof area and system sizing calculator
- Solar production estimate
- Monthly savings estimate
- Payback period calculation
- Proposal summary page

## Project Goal

This repository is intended as a portfolio project to demonstrate:

- full-stack development
- clean UI implementation
- business logic and calculator design
- API and database work
- practical software engineering in a real-world domain
